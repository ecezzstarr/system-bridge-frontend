# Security

Security fixes are maintained on the canonical `main` branch. Production changes use Weave's verified Release Workshop.

If you find a suspected vulnerability, contact company support through https://weavingsystem.online/support and request a private security-reporting channel. Do not post credentials, private customer records or exploit details in public issues. Use synthetic examples and the affected route/version when reporting.

The implementation review and operator follow-up requirements are recorded in `docs/security-hardening-2026-11-19.md`. Registration of the company does not substitute for security verification.
