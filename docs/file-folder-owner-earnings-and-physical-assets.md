# File Folder business earnings — owner operating contract

Implementation branch: `feature/client-file-folder-verified-earnings`.

## One company, distinct owners

A purchased File Folder is an independently owned operating environment within WEAVE. Its systems take the owner's existing life, trade, profession, skill or project into buildable capability, a public Customer Door and business transactions. Every Pro Regional Manager File Folder is tier Pro, but **its commercial workshop belongs to that particular owner**, never a universal crypto exchange. CJ Dorado keeps her individually owned Crypto Exchange Workshop and a separately approved company position and salary. Her business receipts do not become WEAVE payroll.

## Implemented verified earning path

1. An active Client or independently activated Pro Regional Manager owns a File Number and store.
2. Owner publishes a real product, digital service or other authorized offer.
3. Public Customer Door collects an order. Existing Legion Carrier parameters attribute only eligible active employee introductions. Attribution is not a payout.
4. An actual wallet payment atomically debits the buyer and credits the owner, or Administration verifies real funds received into the WEAVE treasury and settles from an already funded treasury account. Each settlement has a unique receipt.
5. The Owner Earnings tab reads the settlement table and summarizes credited Flame Coin, paid orders, fulfillment progress and worker attribution. It does not treat pending orders as earnings.
6. Owner can record incurred operating expenses with category, currency, optional built system and reference. These entries are **owner reports**, not third-party receipts or wallet debits. A unique per-request key prevents retry duplicates.
7. The dashboard shows a provisional Flame Coin remainder after self-reported Flame Coin costs. Different currencies remain separate; no invented conversion or return on investment.

## CJ exchange boundary

CJ's workshop can already keep market research and trade intent journals, and her Customer Door can receive enquiries and sell independently fulfilled legitimate non-trading services. A crypto offer is an **exchange enquiry**; the generic Customer Door payment engine rejects treating it as a completed BTC/USDT trade. An actual exchange requires an authorized provider, documented funding, market price, execution, custody and chain confirmation, asset delivery evidence, reconciliation, customer protection and relevant compliance. Do not present a pending journal as funds, a completed trade or a verified profit.

## Future File Folder in the physical world

The same File Number/owner/business/system architecture can ultimately represent *digital*, *physical* and *hybrid* operated assets: a software workshop, tangible production facility, modular mansion, real estate service or other built property. A physical property sale is **not** created by purchasing a digital File Folder. It requires separate asset IDs, title/deed due diligence, beneficial ownership checks, building permissions, land/location evidence, construction milestones, inspections, contracts, escrow, completion evidence, ongoing maintenance and taxation. Put these capabilities behind dedicated verified modules; never use a simulated 3D castle as proof of real-world property ownership.

A File Folder may eventually have a digital building and a real-world counterpart. Both share the owner and recorded operational work, while ownership of land/buildings must remain an independently verified legal title.
