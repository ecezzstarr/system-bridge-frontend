# File Folder presence and continuity — operating contract

## Principle
WEAVE organizes Presence as a living company environment. It does not command the lives of participants. A Client's File Folder develops through construction, business relationships, employed Legions, customer transactions, and records. Owner attention may leave and return without interrupting authorized work.

The File Folder is not an automatically profitable virtual property. A person directs the business; other real people and operating systems carry defined work. The records make the movement legible when the owner returns.

## Implemented vertical slice
- In the private File Folder's Business Core, the Client sees their own recent commissioned systems, recorded Customer Door orders, independently settled payments, and self-reported Legion work; no fictional activity is synthesized.
- An Agent or Bridger who has voluntarily accepted exclusive Legion employment can record an attributable work note from their Legion workspace. Employment is checked server-side at submission. Work notes cannot create orders, payouts, or earnings.
- Every work note is labeled self-reported; order creation is not a payment; only a funded settlement receipt is payment evidence.
- The Client may choose **Recognize this movement**, storing a monotonic checkpoint. New work after the returned server snapshot remains for the next review. Opening the view does not mark activity as reviewed.
- The interface refreshes while visible, without impersonating a worker or issuing tasks. The owner's private business records are scoped to their active File Number.
- Legions may continue their authorized work whether or not the owner opens the File Folder. Historical reports survive resignation or release, but released workers cannot submit new reports.
- Recognition does not grant employment, move balances, approve work, change product prices, or override the existing Forensics/Administrations settlement authorities.

## Scope and limitations
- This is a real movement-and-recognition feature, **not** a globally autonomous agent. Workers must actually perform and report their tasks.
- Legacy work before these reports existed appears only if it is supported by existing system, order, or settlement records.
- The first owner view is limited to a 30-day lookback. Recent entries are capped, to avoid overload; this is an activity summary rather than a financial audit.
- Self-reported notes do not establish customer consent, delivery, verified productivity, payroll entitlements or guaranteed returns.
- The actual 3D File Folder remains the primary spatial interface; Presence continuity is an operating panel within its existing Business Core building, not a second dashboard or a replacement scene.
- This work does not change Sunshine's banking arrangement, credit permissions, verified interest requirements or the four-month business recovery target.

## Validation
Production Check runs the File Folder presence-continuity regression, plus the repository's existing TypeScript, application build, and integration checks. Staging should additionally test one active Client, a legitimate Legion, a released Legion, an unowned File Number, duplicate submission, a real order with no settlement, and a confirmed receipt.
