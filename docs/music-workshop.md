# WEAVE Music Studio · Words and Sound in Motion

## Purpose

The Music Studio is a **Client-built system in the Streaming district of the File Folder**. It is a production workshop, not the Premium File Folder DJ. It makes a conversation between **Self** and **Environment** audible by arranging words and sounds into a time-accurate repeating musical loop. A project starts with three functioning synthesized sound tracks (Ember / River / Radiance) and four timed word cues; Clients can replace, edit, upload, and record real sounds.

## Construction and authority

- First activate the existing Client Customer Door and Creator Booth.
- The new **Music Studio Kit** and **Music Studio blueprint** are in the existing Client build catalog, requiring one kit and 72 hours of base construction.
- **Unpublished by default:** the Kit is seeded at numeric 0 as a placeholder for an Administrator-set price, never advertised for free use. Administration must set a positive authorized Flame Coin price and publish the Kit and blueprint before public construction begins.
- When the built system `music_studio` becomes **active**, its live system opens the Music Studio route.
- All File Folder tiers use the same ownership / build permissions. No automatic exemption is created for Standard, Pro, Premium, or Plus.
- The Client owns the project and captured audio. Exclusive, active hired **Legions** can use their employing Client's workshop only while employed. Others require an owner-invited Agent, Bridger, or Administrator account; public visitors have no private recording access.

## What is real and operational in the branch

- Web Audio synthesis: Ember lead, River noise/filter texture, Glass, Bass, and Pulse, generated by real audio oscillators, filtering, gain envelopes, and authored notes.
- At least **two audible tracks** are required to start/export a session. Up to 12 tracks can be placed as Self (lead) or Environment (response).
- Each track has an adjustable start beat, 1/2/4-bar recurrence, volume, pan, note and mute. The global project has 4 or 8 bars and a 50–180 BPM clock.
- Beat-aligned sample playback and a per-clip **source BPM** parameter. Playback-rate matching can change sample pitch. There is no claim of high-quality time-stretch or key matching.
- Word cues (up to 32) with position, speaker and exact beat; playback highlights the current words. Word cues **do not produce spoken audio** unless the user records or uploads their own voice onto a sound track.
- Microphone recording through browser permission; upload of WAV, MP3, M4A, OGG, WEBM sound files into WEAVE's private media storage (16 MB per clip; at most 60 clips and 256 MB of stored audio per Client File Folder).
- Actual live FFT output meter, decoded sample waveform previews, stereo mixer, and playable synchronized loop.
- Local bounce to real 44.1kHz stereo WAV through `OfflineAudioContext`, not a screenshot or simulated export.
- Project save, reopen, revision, invited staff access and revoke.
- Real, identified studio photography in the editor: `Mixing desk at the Hipposonic Recording Studio.jpg` by Hipposonic Studios, **CC BY-SA 4.0**, unmodified and attributed in the interface, <https://commons.wikimedia.org/wiki/File:Mixing_desk_at_the_Hipposonic_Recording_Studio.jpg>. Remote host may be unavailable offline; the audio editor and composition still function.

## Private sound storage

All music clips save with randomized paths under `weave-private/music/<client-id>/` and store a separate Client-owned database asset record. The generic public /api/media route explicitly rejects that prefix, and the private media API checks user identity, active built File Folder, present Client authority, asset owner, and file number **at every read**. Staff access is revoked immediately on Legion release or invitation removal. A role or public URL is never permission.

## Current limits

This is a functional browser-based loop creation workshop, not a full DAW. Word cues are not speech synthesis. It does not claim audio separation, pitch-preserving tempo stretch, tuning/key detection, auto-mastering, VST plugins, a sound licensing catalogue, collaborative real-time editing, professional stem export, MP3 conversion, or commercial release distribution. Recorded audio is only exported when the track is included in the beat timeline. A four/eight-bar bounce is one loop, not an automatically generated full-length song.
